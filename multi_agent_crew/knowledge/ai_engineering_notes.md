# AI 工程实践速查笔记(供 RAG 检索)

## 模型路由
生产系统常用「小模型路由 + 中模型生成 + 旗舰模型兜底」的分层结构,
把昂贵能力只投向 5%~10% 真正需要的高复杂度流量,从而控制成本。

## 多智能体协作
关键不是堆 Agent 数量,而是显式协议:task schema、tool contract、
消息总线、黑板共享状态、任务交接规则与失败回退策略。

## 上下文工程
不要把全部历史塞给模型。保留结构化摘要、最近几轮原文、当前任务状态、
Top-K 检索结果与工具返回关键字段,做到信息密度最大化、token 成本最小化。

## 评测与回归
看任务级指标:任务成功率、工具调用错误率、无效重试率、平均解决时长、
单次解决成本、人工接管率。任何 prompt/模型/工具变更都要跑全量回归。

## 安全与成本
涉及钱、数据、生产环境的 Agent 要最小权限、工具白名单、沙箱执行、
敏感操作二次确认、审计日志。安全设计本身就是成本控制。
